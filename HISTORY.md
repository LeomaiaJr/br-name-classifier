# History

This public repository was published from an audited snapshot of the classifier tree on 2026-07-04.

Version 1.1.0 adds the precision-first production policy used by BR Kissimmee
Finder. It keeps the broad ML scorer available for research while adding
independent owner qualification, organization exclusion, count-guarded surname
conflicts, and a 204-case regression corpus for dependable confidence bands.

Earlier private development commits mixed classifier work with application-specific audit notes and benchmark fixtures. The public history starts from this cleaned snapshot to avoid publishing private project context while preserving the MIT license and current source files.
